# AGENTS.md

## Blog Direction

This repository is the personal blog for Seize the Moment, published through GitHub Pages.

Keep the site quiet, readable, and personal. Prefer a calm editorial style over a flashy product or marketing style. The blog should feel like a place for saved thoughts, projects, reading notes, and daily observations.

## Writing Style

Write Chinese posts in a sincere, restrained, reflective tone.

Prefer:
- Clear short paragraphs.
- Concrete observations.
- Simple openings.
- Natural Chinese phrasing.
- A small amount of poetic texture.
- Enough blank space for the writing to breathe.

Avoid:
- Slogan-like language.
- Excessive explanation.
- Generic motivational writing.
- Heavy technical jargon unless the post needs it.
- Overly polished corporate phrasing.

## UI Style

Keep the visual design minimal and warm.

Prefer:
- Generous whitespace.
- Readable typography.
- Soft off-white background.
- Dark neutral text.
- Muted teal accents.
- Simple navigation.
- Article-first layouts.

Avoid:
- Decorative gradients.
- Card-heavy landing pages.
- Loud colors.
- Unnecessary animations.
- Marketing-style hero sections.
- Nested cards or visually busy page sections.

## Technical Rules

This blog should remain easy to publish on GitHub Pages.

Prefer plain static HTML and CSS unless there is a clear reason to introduce a generator or framework.

When adding a new post:
- Create it under `posts/`.
- Link it from `index.html`.
- Keep metadata and page title consistent.
- Verify the page locally before pushing.

When changing UI:
- Reuse existing CSS variables and layout patterns first.
- Keep the reading experience stable on mobile and desktop.
- Avoid unrelated redesigns unless the user asks for them.
